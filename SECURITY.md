# 🛡️ Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions of **EndpointGuard**:

| Version | Supported |
|---------|-----------|
| 5.0.x   | ✅ Yes     |
| 4.x     | ⚠️ Critical fixes only |
| < 4.0   | ❌ No      |

## Reporting a Vulnerability

We take the security of EndpointGuard and the systems it protects very seriously. If you discover a vulnerability or a bypass in our detection engine, please do **not** file a public GitHub issue. Instead, report it responsibly.

### How to Report
Please send a detailed vulnerability report to the maintainer via email:
* **Contact**: `princegaur00001@gmail.com`
* **GPG Key**: *[Insert GPG fingerprint here if available]*

Please include the following information in your report:
1. **Description**: Detailed description of the vulnerability, scope, and potential impact.
2. **Proof of Concept (PoC)**: Step-by-step instructions or exploit script demonstrating the vulnerability or bypass.
3. **Environment**: Linux distribution, kernel version, and EndpointGuard configuration details.

### Our Response Process
1. **Acknowledgement**: We will acknowledge receipt of your report within **48 hours**.
2. **Investigation**: We will investigate the issue and coordinate with you on details.
3. **Patch & Release**: A fix will be developed and released in a patch update.
4. **Credit**: We will gladly credit you for your responsible disclosure in our release notes and `CHANGELOG.md` (unless you prefer to remain anonymous).
